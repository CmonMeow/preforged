Typed attribute storage — 2026-10-09

NetworkServer attribute reads and saves now call NetworkManager's typed methods.
Manager retains serialized database admission and a three-second deadline.
Accounts directly reads and writes the native 54-byte SQLite profile, retaining
ownership, revision CAS, validation, source hash preservation, baseline-only
initial entitlements, and immutable quest bonus/provenance during rank edits.
Offline get/save adapters use the same typed storage functions. Full entitlement
imports remain offline-only. Profession switching remains an atomic legacy
operation pending migration, and gameplay handlers retain profession/point
allocation checks. This change does not widen attribute edit permissions.

accounts_lifecycle all passed. New isolated checks verify foreign ownership,
missing baseline, cancellation, initial entitlement rejection, stale revision,
and rollback after both initial insert and existing-profile update. Diagnostic
failures now report source lines in the persistence test.
