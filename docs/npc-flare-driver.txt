Autonomous hostile Flare controller (2026-10-17)

The previous World had reviewed spellbook configuration and explicit
begin_npc_spell, but no general tick caller that acquired a target, approached,
started a paid spell, completed it and dispatched its effect. The guardian quest
driver only drove authored weapon strikes. Admission tests alone did not make
an autonomous spellcaster. This opt-in controller closes that vertical gap for
Flare194 against player targets.

Host API configure_npc_flare_ai(FlarePolicy,now) requires a live generation-bound
hostile NPC with reviewed actual Energy. Fire Magic,combat level,movement speed,
acquisition/follow/leash ranges,projectile policy and provenance are explicit.
Unknown Energy cannot configure; unknown target Fire armor cannot start a paid
cast. No stock NPC loadout,rank,Energy maximum or regeneration is guessed from
a display name or level. Existing quest-owned actors/motion are rejected to
avoid two competing drivers. Configuring during a cast/projectile is rejected.

The World tick hook drive_npc_flare_locked(now) autonomously acquires a published
living same-plane player within the authored radius. Nearest distance with
actor-ID tie-break is an explicit deterministic private-server policy,not a
recovered retail threat score. Target scope/generation is retained until death,
publication loss,plane mismatch,follow/leash break,then the actor returns home
before reacquisition. Movement uses layered routing when available and existing
NPC movement-integral authority for speed conditions/control pauses. It does
not cross a plane via an invented straight-line route.

In spell range/line-of-sight it calls LiveActor's real Spellbook admission and
payment,with World per-slot disable authority. It honors native activation,
aftercast,recharge and interruption epochs. Completion invokes the same World
before-spell-effect reaction authority (including Backfire) before release.
The delayed projectile keeps a fixed release aim and uses explicit host flight
speed/hit tolerance. Misses or stale/dead targets receive no damage. Accepted
hits use existing native Flare plan,reviewed Fire armor,incoming spell modifiers,
damage/health/death publication and passive-recovery bookkeeping. It cannot
damage before paid cast completion plus flight; repeated same-time ticks cannot
replay the action. Late polling never accumulates multiple historical casts.
