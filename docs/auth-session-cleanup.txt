account identity and the parent session hash. Neither is a new client wire
field. The hash is not the bearer login token and cannot authenticate a user.
The auth handler acquires cleanup immediately after successful authentication,
before roster/profile initialization. Every subsequent exit path releases it.

NetworkComponent/NetworkServer/NetworkManager/Accounts provide typed
releaseGameSession. It bypasses the transitional operation/payload adapter,
uses the manager's three-second admission deadline, and deletes by both
account and hash in a transaction. Cancellation before commit rolls back.
Ticket children cascade. NetworkClient returns unavailable until its custom
transport is implemented.

under the portal lock and revoked outside it. Abrupt server process termination
cannot run destructors; abandoned sessions still expire through stored limits.
