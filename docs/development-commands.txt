Ordinary pet commands:
/namepet name and /petname name rename the user's own animalcompanion;
emptyargument restores that animal's defaultname. No pet exists in currentserver
state, so parser cannot invent success or target another player's companion.

Durable rename proposal (not implemented by parser): resolve target to owned
liveScope, accountID and characterGUID within thisworld; privileged caller must
pass authorization independently of GMlabel. Accounts operation should verify
accountownsGUID, expectedoldname, globalnewnameuniqueness inside atransaction;
keep GUID, summaries, inventory, skillbars, queststate unchanged. Persistfirst,
then update publicagentname and cachedgrant/roster; version/lifetime CAS prevents
renaming a replacementactor after leave. Decide separately whether customized
item ownership is GUIDbased; displaystringrename alone must not grantotheritems.
NPCdisplaynames andpetnames are different typedoperations, not characterrename.

Durable rename backend implemented:
gw-character-development-rename fields: account hex, character GUID hex, expected
current UTF-8 name, new UTF-8 name (tab separated). BEGIN IMMEDIATE protects
ownership, exact old-name compare-and-swap, global ASCII case-insensitive name
uniqueness, and deadline rollback. Only fw_gw_characters.name changes; all GUID
references remain intact. gw-character-name-get returns the current owned name.
rename_accounts_test covers ownership, stale names, duplicate names, cancellation,
inventory identity/revision, roster GUID, and restart durability.
Live command is authorized by private-admins plus enabled /.gm mode. Same-map
target scope and exact current name are held through durable commit. Native88
then updates the existing player record, preserving published appearance/fields
and never spawning a new agent. Evidence: tools/protocol/player_rename_2022.py
and tests/fixtures/player-rename-2022.txt execute original native792080 against
a pre-existing record and prove replacement name + retained lifetime/sentinels.
Owning auth/world sessions refresh roster, selectable names, grant and presence.
Exact cosmetic label repaint timing still needs live client verification.

Live observation: native88 changes the player record and chat sender, but does
not by itself refresh inventory-title or party-row UI caches. The affected
