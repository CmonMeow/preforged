NetworkManager/Component/Server/Client migration
Classes exist in src/network/network.h. Typed requests/results now cover login,
sessions/tickets, character creation/deletion/roster/map transitions, character
state/rename/unlock, skill/attribute state and inventory/storage/trade operations.
The shared boundary now consists of 46 typed virtual application methods.
NetworkServer owns serialization/result decoding and its protected storage
adapter. NetworkManager's storage execution is private. NetworkClient implements
the same typed methods as explicit FW_UNAVAILABLE stubs for the future custom
client, as requested; it has no raw string transport into the local database.
Storage still uses internal operation strings. Native tests pass after this
boundary change. Later live runs verified login, guild/progression panels,
character creation/deletion and world re-entry; two-player trade remains pending.
