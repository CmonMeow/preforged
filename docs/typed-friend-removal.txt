All four friend operations (list/add/remove/blocked) use NetworkServer -> NetworkManager -> Accounts directly. No Operation/string dispatch occurs in these production methods. NetworkManager bounds admission/execution to three seconds. Shared storage helpers in accounts_friends.inc serve both native methods and offline adapters, eliminating duplicate SQL. Reads and mutations use transactions, check owner existence and cancellation, and return native identities/text. Cancelled reads expose no partial records. Addition resolves a character name to an account, rejects self-additions and duplicate aliases, enforces100 friend/10 ignore capacities, and permits updates/conversions subject to capacity. Removal is owner-scoped and idempotent; ignore lookup is directional. Custom-client transport remains unimplemented. Tests cover capacity, aliases, Unicode, cancellation after writes, ownership, conversions, and removal.
