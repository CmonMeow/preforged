Native2022 faction, currencies and title integration

gw_progression.h provides two deliberately separate durable profiles:
Factions is account-shared, four current/lifetime/cap counters in order Kurzick,
Luxon, Balthazar, Imperial. Default earned balances are zero; base caps10000,
10000,10000,20000 are game rules, not claimed official captures. Local mirrored
Balthazar_faction.html states per-account storage and initial10000/max250000;
Kurzick_faction.html and Luxon_faction.html initial10000/max70000; Imperial_faction
cap is the sum of Kurzick/Luxon caps. earn clamps actual granted credit to cap;
spend never reduces lifetime credit. No exchange/deposit/trader rewards invented.

Character holds current/total skill and hero-skill currency counters and proven
title rank definitions/tracks. Empty defaults mean unobserved private progress.
All base fields in title tracks are preserved from native2022 metadata, not
guessed from modern44-byte structs. This does not automatically import official
titles, fabricate achievement ranks, or merge account-bound title progress across
characters. The eventual title import/gameplay rules must implement account-bound
track aggregation separately. No account capture currently supplies these fields.

Persistence core hooks:
top include gw_progression.h; helper include accounts_progression.inc; dispatch
progression_execute(db,operation,fields,permitted) before generic operations.
Tables fw_gw_factions(account PRIMARY KEY REFERENCES fw_accounts(id) ON DELETE
CASCADE,revision INTEGER NOT NULL,profile BLOB NOT NULL), fw_gw_progression
(character PRIMARY KEY REFERENCES fw_gw_characters(id) ON DELETE CASCADE,
revision INTEGER NOT NULL,profile BLOB NOT NULL).
gw-account-faction-get account =>0 when absent, else revision TAB hex.
gw-account-faction-save account TAB expectedRevision TAB hex =>newRevision.
gw-character-progression-get account TAB character =>same format.
gw-character-progression-save account TAB character TAB expectedRevision TAB hex.
Saves are trusted internal server operations, never direct unrestricted client
commands. Validate ownership/CAS and final precommit cancellation rollback.

restore(factions,character,experience,level,morale,playerNumber) replaces existing
packet232 initialization; do not send old zero faction stats after this restore.
It returns232,233..236caps,242rank definitions,245tracks,243active title. CMSG86
DWORDtrackID and87hide have pinned framing. select_title returns immutable proposed
profile only when the track's earned current tier and definition exist. Persist
CAS before broadcasting active_title(playerNumber,tier), tier0 for hide. Player
number is a WORD PlayerArray index, distinct from world agentID.
