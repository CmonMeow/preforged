GM interface
The local wiki's Game_master article distinguishes live GM commands from
staging developer commands. config/private-admins.txt is the account allowlist;
/.gm or /.dev only enables commands for already authorized accounts. It does
not grant account permission or claim to display the official GM label.
/.allskills applies the explicit development grant to the current level20
character; /.s <map ID> uses normal campaign/navigation/arrival preflight;
/.who prints current private character/map/skill/attribute information.
Ban/mute, item spawning, fireworks and other unimplemented commands return
an explicit unavailable response. They are not silently simulated.

Map entry without a configured point
When a destination has a navigation mesh but no explicit configured spawn, the
server targets the map-bounds center and snaps it to the nearest walkable point
on ground plane0. It does not reuse a character's last logout position. A map
without a bound navigation asset uses map-space origin (0,0) because no bounds
are available, and loads without authoritative collision. Private /tp and
portal travel grant all campaigns; unknown map IDs remain rejected. Origin is
only a provisional arrival until that map's navigation asset is available.
