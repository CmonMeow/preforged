407phase0,405chunks,407phase1,405chunks,406type0(map,version). Chunks are at
most1024bytes. Phase0 contains physical file IDs; phase1 contains composite
IDs expanded by the client. Catalog data must come from reviewed captures;
navigation asset IDs alone cannot establish all dependencies.

Default path data/gw/map-manifests.txt. Optional FW_GW_MANIFEST_CATALOG selects
another path. An explicitly configured missing file or invalid catalog fails
with a diagnostic, rather than silently claiming an empty real manifest.
Format, decimal integers, one map per line:
  map version phase0-count phase0-IDs... phase1-count phase1-IDs...

the reserved high bit. Maps1..876 match the pinned native mission table.
