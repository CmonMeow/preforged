Next concrete implementation boundary
drive_npc_ordinary_locked currently returns true for every pending ordinary
windup before either caster driver can examine reviewed spells. It can express
stopping for invalid geometry/control, but cannot deliberately replace a pending
ordinary action with a now-admissible reviewed spell on that same tick.
An explicit reviewed replacement capability could fill that gap: preflight an
exact known spell, current resources/disable/range/target, cancel the owned
ordinary token and ledger only after admission can succeed, then begin/payment
under the same lock. This is a proposed host policy inferred from demonstrated
action transitions. Packets do not prove universal spell-first priority,
resource values, readiness triggers, cancellation cause or priority weights.
