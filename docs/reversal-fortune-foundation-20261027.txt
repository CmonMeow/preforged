Ownership and one-use transaction

---------------------------------

Registry::entry_sequence exposes a scoped monotonic application token. Quotes

retain target lifetime,effect ID,application token,cause,rank,input,time and

split. Consumption revalidates the complete quote at the same event time and

removes exactly that application. Same-ID replacement with identical fields

still changes its token and rejects the old quote. Expiry,removal,forged

amounts,target-generation mismatch,duplicate completion and clock mismatch

reject. Only positive reviewed damage/life-steal inputs are admitted;zero

input consumption is explicitly unresolved. Degeneration,sacrifice,plain

Health loss and blocked/missed attacks must not be fabricated as these inputs.
